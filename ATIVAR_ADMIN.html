Ativar Painel Eduardo

1. Entre no site com a conta que será do Eduardo.
2. Abra o Console Firebase → Authentication → Users.
3. Copie o User UID dessa conta.
4. Firestore → Data → crie a coleção admins.
5. Crie um documento cujo ID seja exatamente o UID.
6. Adicione o campo active do tipo boolean com valor true.
7. Publique as regras incluídas no pacote e entre novamente no site.

admins/{UID_DO_EDUARDO}

active: true

Depois disso, apenas essa conta verá o botão ◆ Painel. Clientes comuns nunca recebem acesso aos dados administrativos.
